UPDATING TABLE OF CONTENTS IN thesis_v2.docx
============================================

The Word file HAS a Table of Contents field embedded, but it needs to be 
populated with actual content. Follow these steps:

OPTION 1: Manual Update (Easiest)
---------------------------------
1. Open docs/thesis_v2.docx in Microsoft Word
2. Go to the "Table of Contents" page (after Dedication, before Abstract)
3. Right-click anywhere on the Table of Contents
4. Select "Update Field" from the context menu
5. Choose one of:
   - "Update page numbers only" (if headings are already there)
   - "Update entire table" (to regenerate from scratch)
6. Click OK
7. Save the document

Word will now populate the TOC with all chapters, sections, and page numbers.


OPTION 2: Command Line Regeneration
------------------------------------
If the file is not open in Word, you can regenerate it:

  cd c:/Users/maaji/Desktop/technical-debt/docs
  pandoc thesis_v2.md -o thesis_v2.docx --toc --toc-depth=3 --number-sections


OPTION 3: Using LibreOffice (Free Alternative)
-----------------------------------------------
If Word is not available:

  soffice --headless --convert-to docx thesis_v2.md
  
Then open the result in any application and it will have a live TOC.


WHY THIS IS HAPPENING
---------------------
- Pandoc inserts a TOC field in the Word XML
- Word only populates the field when it opens the document
- Closing and reopening the file updates the TOC
- Manual update ensures it's current with all heading changes

The TOC is NOT missing—it just needs activation in Word.
